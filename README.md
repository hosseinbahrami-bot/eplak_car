# صفر چی — بازار سوپرپریمیوم خودرو

سایت کامل RTL فارسی. بدون بیلد؛ کافی است پوشه را با یک سرور استاتیک باز کنید.

## اجرا

```bash
cd sefrchi
python3 -m http.server 8080 --bind 0.0.0.0
```

سپس در مرورگر: `http://localhost:8080`

بعد از هر تغییر CSS/JS یک‌بار **Ctrl+Shift+R** بزنید.

## ورود نمونه

- مراجعه: ثبت‌نام با موبایل + رمز (حداقل ۶ کاراکتر)
- ادمین: `09120000000` / `Admin1405!`

ورود مراجعه و ورود ادمین کاملاً جدا هستند.

## ساختار پوشه‌ها

```
sefrchi/
├── index.html              پوسته اصلی (هدر، فوتر، لود اسکریپت‌ها)
├── css/
│   └── style.css           تم زرشکی روز/شب + همهٔ صفحات
├── js/
│   ├── data.js             کاتالوگ، برندها، شعب، خدمات، قیمت‌ها
│   ├── app.js              روتر، صفحه اصلی، لیست آگهی، جزئیات
│   ├── portal.js           ورود، فروشنده، ادمین، برگه کارشناسی
│   ├── estimate.js         تخمین قیمت + نقشه بدنه تعاملی
│   ├── garage3d.js         آتلیه ۳۶۰ درجه
│   └── vendor/             Three.js و لودر مدل (آتلیه)
├── fonts/                  یکان‌بخ و ایران‌سنس
├── images/
│   ├── logo.png            وردمارک سفید
│   ├── logo-mark.png       آیکون مربعی زرشکی
│   ├── body/               برش نوع بدنه
│   ├── flags/              پرچم کشورها
│   ├── garage/             فریم‌های ۳۶۰ آتلیه
│   └── svc-*.jpg           عکس اختصاصی هر خدمت
├── models/                 فایل GLB (آتلیه فعلاً عکس‌محور است)
└── فهرست-فایل‌ها.txt
```

## صفحه اصلی (ترتیب فعلی)

1. هیرو و جستجو
2. نوع بدنه
3. استوری شعب
4. تخمین قیمت (شروع فقط برای اعضا)
5. برندها بر اساس کشور
6. پیشنهادات ویژه
7. بر اساس کاربرد
8. خدمات تخصصی (۰۱ تا ۰۹)
9. فیلترهای پرطرفدار
10. کلاس قیمتی
11. برندهای پرتقاضا
12. مجله
13. آتلیه ۳۶۰

## نکات محصول

- آگهی فروشنده تا تأیید ادمین (`status: published`) روی سایت عمومی نمی‌آید.
- فروشنده می‌تواند قبل از انتشار ویرایش/حذف کند؛ بعد از انتشار ویرایش بسته است.
- ادمین می‌تواند انتشار / بررسی / رد / ویرایش / حذف کند.
- اعداد نمایشی فارسی هستند و با ٬ جدا می‌شوند.
- برگه کارشناسی افقی است، با لوگوی صفر چی و فونت یکان‌بخ / ایران‌سنس.

## حساب‌ها در مرورگر

همهٔ دادهٔ نشست در `localStorage` همین مرورگر است:

- `sc_visitors` / `sc_user` — مراجعه
- `sc_admins` / `sc_admin_session` — ادمین
- `sc_ads` / `sc_certs` / `sc_chats` / `sc_cms`
